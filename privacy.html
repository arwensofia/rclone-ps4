Privacy policy

Last updated: 22 October 2026

rclone PS4 is a personal setup used only by its owner. It uses the open-source program rclone to access the owner's own Google Drive from the owner's own home media server.

What data is accessed

With the owner's permission, rclone reads files in the owner's Google Drive so they can be played on the owner's home network. The Drive is mounted read-only on the media server.

How data is used and shared

Data is used only to show and play the owner's own files on the owner's own devices. Nothing is sold, shared with anyone else, or sent to any server other than Google's. The sign-in token is stored only on the owner's media server.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue on this site's GitHub repository.
